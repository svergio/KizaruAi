# Pic: режимы — стоп-кадры

Три режима серого (не simple). Цветной оригинал → энкодер. **Без diff.**

| Файл | Mode | Tone | Что это |
|------|------|------|---------|
| `0_source.png` | — | — | цветной исходник |
| `1_line.png` | **line** | Rec.601 | линии + shade-фон |
| `2_render.png` | **render** | OKLab L* + color edges | усиленный цвет / контур |
| `3_details.png` | **details** | OKLab L* | soft 2×2 словарь (mid-band) |

## Семпл (верно)

1. Исходник при необходимости **upscale** nearest до сетки `cols×rows` смайлов.
2. Один смайл = **2×2 квадранта**.
3. Квадрант = mean блока **`scale×scale`** пикселей исходника.
4. Итого на смайл: `(2·scale)²` исходных px. При `scale=2` → 4×4 px на смайл, **4 значения** (по mean каждого квадранта) в словарь.

## Размер PNG

CLI-дефолт: **`cells=320`** колонок смайлов × **`OUTPUT_SMILE_PX=8`** → ширина **2560**.  
(Старый gold `*_c160` был 160×8=1280 — не путать.)

`scale` меняет только семпл с исходника (px на квадрант), не размер выходного PNG.

python notebooks/research/pic_mode_stills.py --cells 320 --scales 1 2 3 4
